Pola yang dipakai di semua halaman
  • Tabel: pencarian, filter, sort dengan penanda arah, paginasi 10/25/50, total dan rentang, Reset Filter, View di setiap baris.
  • State tabel: loading, kosong, tidak ada hasil, error dengan Coba Lagi. Filter dan sort tetap saat kembali dari detail.
  • Dialog: judul, identitas target, akibat spesifik, Batal, tombol dengan kata kerja, loading anti klik ganda, umpan balik berhasil atau gagal. Alasan wajib untuk tolak, block, cabut, dan perubahan sensitif.
  • Tanpa dialog untuk View, cari, filter, sort, paginasi, ganti tab, dan membuka form.
  • Tidak ada pendapatan, pembayaran, payout, komisi, wallet. Tidak ada password, token, API key, prompt, atau isi chat di layar admin.
